# Expected Outputs

The scripts generate experiment-specific output folders under `outputs/` or the output directory specified inside each script/config.

Typical outputs include:

- tuning grids
- selected VGIB configurations
- out-of-fold predictions
- primary performance tables
- weak-alignment diagnostics
- beta sensitivity tables and figures
- auxiliary/gated fusion tables
- nested beta selection tables
- boundary subgroup contribution tables
- synthetic benchmark metrics
- t-SNE coordinates and figures

Because raw data are private, output files are not committed to this repository.
