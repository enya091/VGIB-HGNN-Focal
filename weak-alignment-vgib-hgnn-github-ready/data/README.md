# Data

Raw biomedical data are not included due to privacy and data-use restrictions.

To reproduce the real-cohort experiments, place the following files here:

- `data.csv`: demographic covariates and diagnosis labels
- `micro.csv`: gut microbiome abundance table
- `all_brain_result_1(3).csv`: brain MRI ROI features

Expected label setting:

- `Normal` -> 0
- `MCI` or `Dementia` -> 1

Do not commit private cohort files to GitHub.
